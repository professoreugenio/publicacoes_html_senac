Sobre o curso

Este curso foi criado para alunos que desejam iniciar na área de desenvolvimento web. Durante as aulas, o aluno aprenderá a montar páginas HTML, aplicar CSS e organizar projetos.

O que você vai aprender

  1. Estrutura básica do HTML.
  2. Criação de títulos, parágrafos e listas.
  3. Aplicação de CSS externo.
  4. Organização de arquivos e pastas.
  5. Boas práticas de escrita de código.

Informações do curso

  • Carga horária: 20 horas
  • Modalidade: presencial
  • Nível: iniciante
  • Projeto final: mini site com HTML e CSS
